# About

## Опис проєкту
Це API для внутрішньої системи соціальної мережі **Social Network**.
Воно дозволяє керувати користувачами (User) та їхніми публікаціями (Post).

## Основний стек
- **Specification:** OpenAPI 3.0.3
- **SDK Generator:** OpenAPI Generator (TypeScript Axios)
- **Documentation Engine:** Zudoku
